## 🪟 Window Management

| Keybinding | Action |
|------------|--------|
| `Super + h/j/k/l` | Focus window (left/down/up/right) |
| `Super + Shift + h/j/k/l` | Move window |
| `Super + I` then `h/j/k/l` | Resize window (exit with `Esc`) |
| `Super + V` | Toggle floating |
| `Super + Shift + Q` | Close window |
| `Super + T` | Toggle split (dwindle) |
| `Super + F` | Fullscreen |
| `Super + Shift + F` | Maximize |
| `Super + Shift + P` | Pin window |
| `Super + G` | Toggle group/tabbed |
| `Super + Tab` | Next tab in group |
| `Super + Shift + Tab` | Previous tab in group |

## 🎯 Pro Tips

1. **Vim Navigation**: All `h/j/k/l` keys follow vim conventions
   - `h` = left, `j` = down, `k` = up, `l` = right

2. **Workspace Switching**: Three methods available
   - Numbers (1-9/0) for direct access
   - Brackets ([/]) for sequential navigation
   - Arrow keys (left/right) for sequential navigation

3. **Scratchpad**: Use minus key (`-`) as it's easy to reach and remember

4. **Quick Lock**: `Super + Escape` is intuitive for locking

5. **Close vs Exit**: 
   - `Super + Shift + Q` closes current window
   - `Super + M` exits entire Hyprland session

6. **Screenshot Workflow**:
   - Quick share: `Super + Shift + S` (copies to clipboard)
   - Save file: `Super + Ctrl + S` (saves to ~/Pictures/Screenshots/)

---

**Legend**: `Super` = Windows/Command key (mainMod)
